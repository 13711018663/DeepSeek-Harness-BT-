# BT搜索

在 DSH 左侧栏提供一个 BT / 磁力资源搜索面板，聚合两个数据源：

- **磁力猫（cilimao.app v3.0）**——中文 BT 索引，新片索引快（`clm17.vip`，备用镜像 `clm9.in`）。
- **动漫花园聚合（Anime Garden）**——聚合 动漫花园 / 蜜柑计划 / 萌番组 / ANi。

## 功能

- **搜索**：输入关键词（动漫、漫画、音乐、影视、游戏等）回车即搜；来源可切「全部 / 动漫花园 / 磁力猫」。
- **精准 / 广泛**：广泛为任一关键词命中即返回；精准要求标题同时包含全部关键词。
- **类型筛选**：全部 / 动画 / 漫画 / 音乐 / 日剧 / RAW / 合集 / 特摄 / 游戏（对磁力猫按标题推断）。
- **排序**：发布时间、文件大小、名称。
- **分页**：每页条数可选（10 / 20 / 50 / 100，默认 20，记忆上次选择），结果下方为网页式翻页（上一页 / 下一页 / 页码 / 跳页）；「全部」来源并行抓取各来源并把磁力猫前 240 条并入同一个列表全局排序，每页天然混合各来源。
- **结果卡片**：类型、格式化大小、发布时间、文件数、文件格式、来源站点与发布者；提供「磁力链接」「复制磁力」「详情页」。
- **搜索历史与收藏**：历史保留最近 20 条、可清空；收藏按标题去重，持久化在本地浏览器。
- **返回主页**：一键清空关键词与筛选，回到最近搜索入口。

## 数据怎么来的

浏览器无法直连磁力猫（该站不返回 CORS 头），因此插件的 Host 半在自己的进程里抓取上游，再通过同源只读路由 `/plugins/dsh-plugin-bt-search/search` 交给页面。接口细节见 [数据源说明](SOURCES.md)。

## 桌面客户端

同一套搜索能力另有独立 Windows 桌面版（不依赖 DSH，来源更多：磁力猫 / 动漫花园 / Nyaa / The Pirate Bay / EZTV / BTDig）。

- 安装版 `BT-Search-Setup-1.2.2-win64.exe`：装到当前用户目录、无需管理员，自动创建快捷方式与卸载项
- 便携版 `BT-Search-Portable-1.2.2-win64.zip`：解压即用

下载见 [GitHub Releases](https://github.com/13711018663/DeepSeek-Harness-BT-/releases/tag/v1.2.2)，源码与安装包构建脚本在仓库 `desktop/` 目录。

## 边界

- 磁力猫有「点击访问」人机验证；插件在 Host 侧自动完成（`POST act=challenge`），失败时该来源单独报错，其它来源照常返回。
- 磁力猫每页 12 条、单次搜索最多 80 页（约 960 条）：接口按 offset/limit 换算站点页码取窗口（单次请求上限 120 条），第 1 页串行过验证门、其余页最多 4 路并发；单源「磁力猫」可翻满 960 条，「全部」来源为兼顾速度并入前 240 条（状态行如实标注站点上限）。
- 磁力猫是中文索引，纯英文关键词可能没有结果。
- 磁力猫服务端搜索是 AND 语义，因此**广泛模式只发送最长的一个关键词**，与动漫花园的 OR 语义不同。
- 磁力链接由系统默认下载器（迅雷 / BitComet 等）接管，插件本身不下载文件、不保存任何凭据。
- Host 半更新后需要重启一次 DSH 才生效；未生效时面板自动回退到动漫花园直连。

# BT搜索

在 DSH 左侧栏提供一个 BT / 磁力资源搜索面板，数据来自动漫花园聚合索引（Anime Garden，聚合 动漫花园 / 蜜柑计划 / 萌番组 / ANi）。

## 功能

- **搜索**：输入关键词（动漫、漫画、音乐、影视、游戏等）回车即搜。
- **精准 / 广泛**：广泛为任一关键词命中即返回；精准要求标题同时包含全部关键词。
- **类型筛选**：全部 / 动画 / 漫画 / 音乐 / 日剧 / RAW / 合集 / 特摄 / 游戏。
- **排序**：发布时间、文件大小、名称。
- **结果卡片**：类型、格式化大小、发布时间、来源站点与发布者；提供「磁力链接」「复制磁力」「详情页」。
- **搜索历史与收藏**：历史保留最近 20 条、可清空；收藏按标题去重，持久化在本地浏览器。

## 边界

- 插件在浏览器内直接访问 Anime Garden（该接口允许跨域），因此**只含动漫花园聚合这一个数据源**。Nyaa / The Pirate Bay / BTDig 等站点没有跨域许可，浏览器直连会被拦截。
- 磁力链接由系统默认下载器（迅雷 / BitComet 等）接管，插件本身不下载文件。
- 界面文案为中文。
